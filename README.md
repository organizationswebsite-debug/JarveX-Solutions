# JarveX Solutions — Premium Truck Dispatch Website (v3)

Next.js 14 (App Router) site for JarveX Solutions, restyled in a bold "Pixel Rise"-inspired
design language: cream/black/orange palette, blocky Space Grotesk headlines, bracketed
mono tags like `[1/6]`, tilted trading-card equipment listings, and a numbered gradient
process section.

## Design System
- Palette: Stone `#EDEAE3` (bg), Ink `#111111` (text/black), Orange `#FF6A1A`, Orange2 `#FF8F4D`, Maroon `#6E1E1E` (gradient accent)
- Type: Space Grotesk (headings) + Inter (body) + JetBrains Mono (tags/labels)
- Header: floating cream glass pill nav with Services + Company mega-dropdowns
- Signature elements: tilted "trading card" equipment tiles that straighten on hover, a 4-panel orange→maroon numbered step section, orange shimmer headline accent, bracketed section tags

## Pages
- `/` — Home (hero, stat ticker, network cards, 4-step process, fleet trading cards, services strip, testimonials, CTA)
- `/services` — Service index + `/services/[slug]` dynamic template (intro, slide carousel, detail grid)
- `/fleet` — Equipment index + `/fleet/[slug]` dynamic template (Dry Van, Reefer, Flatbed, Power Only — rates, demand, lane snapshot)
- `/pricing` — 3-tier flat-rate pricing
- `/about` — Story, values, timeline
- `/testimonials` — 9 testimonials
- `/careers` — Open roles + perks
- `/blog` — Index + `/blog/[slug]` dynamic article template (3 sample posts)
- `/faq` — Accordion FAQ
- `/contact` — Contact form (Nodemailer via Gmail App Password)

## Images
Truck/equipment photography is pulled live from Unsplash's free-to-use source endpoint
(`source.unsplash.com`) via plain `<img>` tags — no image files ship in this repo, and no
API key is required. Swap any `src` in `lib/fleet.js` or `components/HeroVisual.jsx` for
your own photography whenever you're ready.

## Setup

```bash
npm install
cp .env.local.example .env.local
```

Edit `.env.local` with a Gmail address + [App Password](https://myaccount.google.com/apppasswords):

```
GMAIL_USER=your-email@gmail.com
GMAIL_PASS=your-16-character-app-password
```

The same credentials power both `/api/contact` (carrier inquiries) and `/api/careers`
(job applications, including the resume file as an email attachment — max 5MB, PDF/DOC/DOCX).

Run:

```bash
npm run dev
```

## Adding more services, equipment, or blog posts
Edit `lib/services.js`, `lib/fleet.js`, or `lib/blog.js` — every entry automatically gets
its own page with no extra routing code needed.

## SEO
- `app/sitemap.js` and `app/robots.js` generate `/sitemap.xml` and `/robots.txt` automatically — no extra config needed.
- Full Open Graph + Twitter Card metadata, plus a generated 1200×630 share image (`app/opengraph-image.png`), so links posted on social media / iMessage / Slack render with a real preview card.
- JSON-LD structured data (`MovingCompany` schema) is injected in `app/layout.jsx`, including the Moaz Group parent-organization relationship and social profile links.
- `app/icon.png` and `app/apple-icon.png` are auto-detected by Next.js as the favicon and Apple touch icon — no manual `<link>` tags required.
- **Before going live:** update `SITE_URL` in `app/layout.jsx` and `app/sitemap.js` from the placeholder `https://www.jarvexsolutions.com` to your real production domain, and swap the placeholder social URLs in `components/Footer.jsx` / the JSON-LD `sameAs` array for your real profiles.

## Performance
- `next.config.js` sets long-lived immutable caching on build assets and generated images, plus `compress: true`.
- Fonts load through `next/font` (self-hosted, zero runtime Google Fonts request) with `preload` enabled for the two fonts used above the fold.
- `<link rel="preconnect">` / `dns-prefetch` hints are set for the Unsplash image domains used throughout the site, shaving connection time off the largest images.
- All below-the-fold images use `loading="lazy"`.
- Every route is statically generated by default (no server-side data fetching), which is the fastest configuration Next.js supports on Vercel.

## Deploy
Push to GitHub → import into Vercel, or `npm run build && npm run start`. Add `GMAIL_USER` / `GMAIL_PASS` as environment variables in your hosting dashboard.
